    Dev Philosophy
    
    
    
    
    
      
    1Fail closed: a gate that cannot verify must refuse, never guess
    
      
    2RED before GREEN — the failing test is half the proof
    
      
    3Every external action pinned to a full commit SHA, every dependency in a lockfile
    
      
    4Nothing reaches production outside the merge queue — no manual deploys, ever
    
      
    5Six AI models argue over my code before it ships — unanimity or it doesn't merge
    
      
    6Evidence over narrative: logs, SHAs and run IDs, or it didn't happen
    
      
    7From idea to deployed edge worker is my favorite journey
